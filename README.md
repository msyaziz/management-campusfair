# Management Campus Fair 2027

**Management Campus Fair 2027** adalah sebuah aplikasi berbasis web yang dirancang khusus untuk memfasilitasi dan mengelola seluruh proses rekrutmen panitia (staff) untuk event Campus Fair 2027. Aplikasi ini dibangun dengan menggunakan PHP dan database MySQL.

## Deskripsi Aplikasi

Aplikasi ini mendigitalkan dan memusatkan alur kerja rekrutmen, mulai dari pendaftaran awal hingga penentuan akhir staff yang lolos seleksi. Sistem ini mendukung kolaborasi antara panitia inti (Admin) dan tim penilai (Pewawancara) melalui sistem hak akses yang terpisah (multi-role).

Berikut adalah fungsionalitas utama dari aplikasi ini:

- **Manajemen Data Pendaftar**: Mengelola data diri, asal kampus/jurusan, kontak, dan pilihan divisi dari setiap calon staff yang mendaftar. Admin dapat melakukan penyaringan, mengubah status seleksi, dan menempatkan pendaftar ke divisi yang sesuai.
- **Sistem Plotting dan Wawancara**: Admin dapat mendistribusikan (assign) calon staff kepada pewawancara tertentu. Pewawancara memiliki dashboard khusus untuk menginputkan nilai (seperti skor komitmen, prioritas, dan keyakinan), memberikan catatan/komentar wawancara, serta memperbarui status wawancara kandidat.
- **Rekap Staff Final**: Menyediakan daftar pendaftar yang telah resmi diterima (diterima) menjadi staff, lengkap dengan divisi tempat mereka bernaung.
- **Pencarian dan Filter Dinamis**: Memudahkan pencarian nama pendaftar secara real-time dan pemfilteran data berdasarkan status wawancara maupun status kelulusan.

Aplikasi ini bertujuan agar proses rekrutmen berjalan transparan, terstruktur, serta mempermudah panitia dalam membuat keputusan penempatan divisi.
